# About MyPersonaOS

> **"What deserves attention today?"**

MyPersonaOS is a personal-first life operating system designed to simplify focus, idea capture, project execution, content creation, and continuous language learning.

---

## Core Philosophy

Modern productivity tools often turn into high-friction databases where users spend more time organizing tasks than executing them. MyPersonaOS takes a different approach:

1. **Today-First Focus**: Everything in the app serves to answer one core question: *What deserves attention right now?*
2. **Low-Friction Capture**: Capture thoughts, tasks, and content ideas instantly into an Inbox without stopping to classify them upfront.
3. **Data Ownership & Privacy**: Your life data belongs to you. In V0.1, data stays local in your browser. In V0.2, data syncs privately via user-owned Supabase instances with strict Row-Level Security (RLS).
4. **Open Source & Extensible**: Built openly so individuals can host, inspect, modify, and tailor the operating system to their personal workflows.

---

## Product Domains

### 1. Today Dashboard
The daily command center displaying high-priority focus items, active tasks, daily progress, and fast capture options.

### 2. Fast Capture & Inbox
A frictionless input buffer designed for instant text or voice notes. Capture first, categorize later.

### 3. Tasks & Projects
A goal-aligned hierarchy mapping broad objectives into actionable projects and daily tasks:
`Goals → Projects → Tasks → Today`

### 4. Content Studio
A multi-brand content pipeline supporting three content identities:
- **CodeToday**: Software development, engineering, and tech tutorials (English-first).
- **Personal**: Technology, science, career, philosophy, and personal insights.
- **Quant Base**: Quantitative finance, trading systems, and institutional content.

### 5. English Lab
An evolving language acquisition system combining listening, reading aloud, comprehension, vocabulary tracking, and spoken retelling.
