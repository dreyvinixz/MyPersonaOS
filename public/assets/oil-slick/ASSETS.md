# Oil Slick visual assets

These assets belong to the MyPersonaOS visual system and are stored locally so the UI does not depend on third-party CDNs.

## Included

- `oil-slick-mesh.svg` — full-page dark iridescent background.
- `oil-orb.svg` — decorative Today/dashboard orb.
- `empty-flow.svg` — abstract empty-state illustration.

## Direction references

The visual direction was researched against:

- Haikei — SVG generators such as blurry gradients, blobs, and layered waves. Haikei states generated designs can be used for personal and professional work and do not require attribution.
- Open Doodles — open illustration system released under CC0. Used as a reference for the idea of lightweight local SVG empty states; no Open Doodles artwork is copied into these files.
- Real oil-slick / iridescent references — used only to establish the dark base and color-shift palette.

## Ownership

The SVG files in this directory were created specifically for MyPersonaOS and do not embed third-party stock artwork.
